## How to take them

1. Open `powerbi/Patient360.pbip` in Power BI Desktop and refresh.
2. Press **Ctrl+Shift+F** or use **View > Page view > Actual size** so the page isn't cut off, and collapse the Filters, Visualizations and Data panes on the right.
3. Capture the report canvas only (Windows: **Win+Shift+S**, then pick the area). Leave out the ribbon and the Windows taskbar.
4. Save as PNG with the names above.

Keep them under about 1 MB each; around 1600 pixels wide is plenty. PNG keeps the text sharp.

Check the Patient 360 screenshot before adding it: the patient names are synthetic, but it's a good habit to look at a patient-level screen before publishing it.
